  carries no selection-on-affinity. network vs discovery is an
  upper bound that includes that selection.

------------------------------------------------------------------------------
3. PRIMARY: STRATIFIED BY (AGENT, FEED SLOT), SLOTS 0-4
   Holds the agent AND the feed position fixed; tier varies across
   rounds within a stratum. This is the identified estimate.
------------------------------------------------------------------------------
   Why this stratum and not (feed, slot): a slot holds exactly one
   post, so a (feed, slot) stratum can never contain two tiers.
   Why slots 0-4: network posts NEVER occupy slots 5-11, so over the
   whole feed tier and position are structurally collinear -- a logit
   on network vs discovery with slot dummies is literally singular.
   Slots 0-4 are where all three tiers actually compete.

   mean slot within 0-4, network    1.72  (n=11459)
   mean slot within 0-4, fof        2.92  (n=1545)
   mean slot within 0-4, discovery  2.18  (n=9681)

    network vs discovery  OR   3.51  95% CI [ 3.06,  4.04]  p=3.31e-70  (1296 strata)
        fof vs discovery  OR   2.34  95% CI [ 1.64,  3.35]  p=2.79e-06  (301 strata)
    network vs fof        OR   1.85  95% CI [ 1.38,  2.48]  p=3.97e-05  (218 strata)

  Compare against section 2, where position is NOT held fixed:
  controlling for slot roughly halves the tier effect, so about half
  the crude gap was the feed builder putting network posts on top.
  What remains is the tier itself.

------------------------------------------------------------------------------
4. WHY THERE IS NO MULTIVARIABLE LOGIT FOR TIER
------------------------------------------------------------------------------
  Because tier is not separately identified from position in this
  design. The feed builder assigns network to slots 0-4, fof to 1-7
  and discovery to all 12, so on the network-vs-discovery subset the
  slot dummies for 5-11 predict 'not network' perfectly and the
  Hessian is singular. Fitting slot as a single linear term hides
  that rather than solving it, and the resulting estimate is not
  stable: dropping the fof rows moves the network OR from 1.76 to
  5.52 without any change to the contrast being estimated.
  The stratified estimate in section 3 is reported instead, because
  it conditions on exactly the strata where the comparison exists
  and discards the rest rather than extrapolating into them.

6. IS THE EFFECT STABLE ACROSS RUNS, OR DRIVEN BY ONE?
   Same stratified estimator, computed run by run.
------------------------------------------------------------------------------
  run                   network vs discovery          fof vs discovery
  baseline               5.77 [ 3.35,  9.94]                        --
  v10_register           3.73 [ 2.33,  5.97]       2.90 [ 0.78, 10.83]
  v10_rep3               3.04 [ 1.92,  4.83]       6.05 [ 2.16, 16.91]
  v10_rep4               4.65 [ 3.18,  6.79]       2.91 [ 1.10,  7.65]
  v10_rep5               4.13 [ 2.59,  6.57]       2.16 [ 0.55,  8.40]
  v10_rep6               2.57 [ 1.81,  3.65]                        --
  v10_replicate          3.04 [ 2.06,  4.47]       3.15 [ 0.52, 18.94]
  v8_full                1.85 [ 1.32,  2.60]       1.17 [ 0.66,  2.06]
  v9_feedback            8.67 [ 4.95, 15.21]      17.42 [ 3.19, 95.02]

  network vs discovery: positive in 9/9 runs, individually significant in 9/9.
  fof vs discovery: individually significant in only 3/7 runs.
  The direction is consistent; the magnitude is heterogeneous. The
  fof contrast is the weaker of the two per-run and leans on pooling,
  so it should be reported as suggestive rather than established.

7. INDEPENDENT REPLICATION ON THE PRE-THREE-TIER RUNS
   Those runs label sources 'following' (came from someone you
   follow) and 'recsys' (ranked in by similarity) -- the same
   contrast under a different feed implementation.
------------------------------------------------------------------------------
  full_twhin       OR   4.79  95% CI [ 3.14,  7.32]  (87 strata)
  full_twhin_v2    OR   5.14  95% CI [ 3.65,  7.22]  (135 strata)
  POOLED           OR   5.00  95% CI [ 3.83,  6.52]  p=1.84e-32  (222 strata)

  A separate feed implementation, a different source vocabulary,
  and earlier prompt versions reproduce the same effect. This is
  the strongest evidence that the result is not an artefact of
  one feed builder.
